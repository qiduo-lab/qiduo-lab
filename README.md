## 作品

### [AI 对话转发器](https://github.com/qiduo-lab/ai-conversation-forwarder)

像微信的「合并转发」一样，在一个 AI 对话里勾选几条消息，一键复制，粘贴给另一个 AI。支持 Claude 和 ChatGPT。

起因是我经常让不同的 AI 独立判断同一个问题，却没有一个顺手的办法，把原话连同"谁说了什么"一起搬过去。于是我和 Claude 一起，用一个下午把这个念头变成了能用的工具。后来 ChatGPT 网页改版、脚本失效，又用一份诊断信息定位问题，当晚修好。

`油猴脚本` `Claude` `ChatGPT`
